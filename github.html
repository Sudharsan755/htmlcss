Initial Setup for git repository

Download Git
git --version = check git installed
git config global user.name 'username'
git config global user.email 'emailid'

Git Commands and Usage

  • git init =initialization of git
  • git status =tells the current status of git
  • git add . = add the files to the git
  • git commit -m "message" = create a savepoint with message
  • git push -u origin main =push towards our git repository
  • git branch branchname = creates a mini version like branch to try some update
  • git checkout branchname = to move the branch mentioned
  • git log = tells the committ history
  • git clone url = make a copy of githu repository to our local system.
  • git diff branchname branchname = Shows line-by-line modifications
  • git merge branchname = checkout to which repo to merge with and enter the branchname
  • git reset filename (or) git restore --staged file = Unstage a file or reset to a previous commit
  • git revert a1b2c3d = Undo a commit by creating a new commit
  • git stash = Temporarily save uncommitted changes (e.g.,to switch branches)
  • git stash pop = Restores the most recent stash
  • git pull = Fetch and merge remote changes.(Combine remote repo wiht our repo)
